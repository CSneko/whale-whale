# Genesis 情绪演化

[English](guide.md) | 中文

## 变更

即时情绪改为接近由心境决定的水平，不再统一趋零；持续的情绪以有界增益缓慢影响心境。情绪设置新增必填的 `offlineChanges`、`moodEmotionScale` 和 `emotionMoodInfluence`，自定义设置客户端须与生成的 Remote 定义一并更新。

缺少这些字段的既有版本 3 锚点仍可读取。启动时先按旧规则结算独立恢复，再记录新增设置，保留身份和历史。旧版严格读取器会拒绝新增字段；版本 1 和 2 的转换要求保持不变。

## 迁移

1. 停止所有使用该生命的进程。升级前保存两个存储域、已验证的备份清单及其 `.d` 目录，保留这份副本供回滚使用。
2. 一并重新构建当前 Host、客户端及生成的 Remote 定义。打开“设置 → 情绪 → 情绪设置”，停机计时开关默认开启，保留按墙钟经过时间计时的行为；关闭后只计算运行时间，保存时会先结算旧策略。
3. 检查耦合增益：`moodEmotionScale` 默认为 0.2，`emotionMoodInfluence` 默认为 0.25。只有希望恢复即时情绪趋零、心境独立回归基准时，才将两者均设为零。这些是模拟设置，不是心理测量值。
4. 重启后核对生命身份、已保存开关及增益保持不变。关闭停机计时后，进程每隔 `emotion.clockCheckpointMs`（默认 60000）及正常退出时保存在线锚点。崩溃后从最后一次成功检查点恢复，排除未提交的运行区间；存储阻塞可能延长这一区间。
5. 回滚时先停止新版进程，再完整恢复已验证的升级前主存储与备份副本。不要从运行中的存储删除个别字段，也不要修改不可变历史。参见[情绪行为](../../../genesis/emotion.zh.md)。
