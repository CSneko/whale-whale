# Genesis 生命模式与记忆模型配置

[English](guide.md) | 中文

## 变更

Genesis 生命覆盖配置使用 TypeSafe Jev 决策，替代对话 LLM 决策。Web 配套插件添加生命模式，并将其设为部署默认值，保留已有用户预设选择。初生行为和工具学习仅用于生命模式，原有四个模式共享身份与记忆，同时保留任务行为。初始化由用户主动点击按钮；“不再出现”会持久关闭自动凭据提醒。命名后会打开首次对话，并触发带系统来源标识的内置问候。

## 迁移

1. 重新构建受影响的主机和浏览器包，沿用同一 `DSH_HOME`、存储、备份和租约重启，不要删除或重建已有生命。
2. 打开“设置 → 知识库”，配置 Jev 端点、模型和凭据，或选择已有提供方以保留通用 LLM 决策；同时配置独立写入模型和嵌入。图形配置优先于部署值，参见[记忆配置](../../../genesis/memory.zh.md)。
3. 备份须包含 `genesis_model_settings`、`genesis_embedding_settings` 两个存储域及凭据库，生命 JSON 备份不包含这些配置。
4. 确认生命模式与其他预设一同显示，并点击“初始化生命”命名或进入待开始的首次对话；首次文字回复成功完成后按钮消失，重启后保持完成状态。记忆失败会单独显示失败阶段和安全的具体原因，对话可继续；失败轮次的实时证据仍在时可重试。

5. “设置 → 记忆”管理记录，并可手动将选中记忆归纳为一条或多条有来源推断，成功后原子替换原始记录。“知识库”配置模型与嵌入。生命模式内置回忆与时间感知；已完成回复支持手动生成记忆，同时保留自动评估。

6. 首次写入前保留可信的升级前生命备份。可选经历元数据、关联及以往认识扩展版本 1 的生命记录，旧记录仍可读取，旧版严格读取器会拒绝新字段。接受用户输入后默认执行有界嵌入关联；设置 `memory.associationLimit: 0` 可保留仅工具回忆。在“记忆”查看经历时间和以往认识，不回填旧对话。

7. 空闲巩固复用记忆更新模型与嵌入，可在“设置 → 记忆”关闭。旧版严格读取器需要写入前备份才能恢复可选 `habit` 与 `consolidation` 字段。身份与记忆保留，待处理任务与失败跨重启保存；不回填旧对话作为习惯证据。辅助推理默认使用 `auto`；设置 `memory.reasoningEffort: provider-default` 可沿用提供方的推理档位。

8. 生命覆盖配置启用 `emotion: {}`，每次符合条件的交流增加一次决策及至多一次写入。情绪子记录现写入版本 2，保留生命身份；升级及回退步骤见[情绪与关系升级](../genesis-affective-state-v2/guide.zh.md)。

9. “设置 → 情绪”持久保存评估与恢复选项，以及需填写原因的手动调整。旧版严格读取器拒绝可选 `controls`，降级须保留写入前备份。已保存选择优先于部署默认值，暂停停止自动情绪推理，恢复与上下文继续生效；修订冲突后请重新载入。
