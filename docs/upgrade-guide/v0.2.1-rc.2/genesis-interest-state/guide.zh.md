# Genesis 兴趣状态

[English](guide.md) | 中文

## 变更

可选 `interest` 配置会在版本 1 的 Genesis 生命投影中新增 `interests`，并在启动及交流完成后追加 `interest.*` 生命事件。原有生命 ID、诞生时间、记忆、情绪和 Session 日志保留。当前读取器接受没有此字段的旧生命记录；旧版严格读取器拒绝新写入的兴趣状态。工作区生命覆盖配置默认启用 `interest: {}`。此功能需要独立记忆写入路由。

## 迁移

1. 停止旧 Genesis 进程，保留两个 Genesis 存储域及独立备份的可信副本。继续使用相同的 `DSH_HOME`、租约路径和存储路由。
2. 重新构建主机与 Web 产物，使用 `interest: {}` 或提供的生命覆盖配置启动更新后的 `dsh` profile。不要删除无法读取的生命以重新初始化。
3. 打开“生命信息”，确认新生命的兴趣初始为空，或重启后原有兴趣记录与生命 ID 均保留。完成交流后可以形成有归属的兴趣阶段；查看其来源 ID 和变化历史。
4. 如需运行旧代码，须同时恢复经验证的兴趣启用前存储与匹配备份。仅移除配置不会删除已保存的兴趣记录。证据限制见[兴趣行为](../../../genesis/interest.zh.md)。
