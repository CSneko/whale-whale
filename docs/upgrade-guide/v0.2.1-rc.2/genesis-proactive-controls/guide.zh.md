# Genesis 主动消息控制

[English](guide.md) | 中文

## 变更

源码工作区的 Life 覆盖配置以暂停状态加载 Social Initiative，并提供“设置 → 主动消息”。原本明确配置 `socialInitiative: {}` 的部署仍默认启用；持久化操作者设置覆盖部署默认值。缺少设置或游标的旧队列仍可读取，添加新字段时保留原有机会与回执；旧版严格读取器会拒绝新增字段。

助手回执投影使用状态版本 2，可从已有 Session 事件重建；不更改 Session 格式，也不要求手工编辑日志。崩溃后无法确认的预约转为不确定，不自动重发。

## 迁移

1. 停止使用该生命的进程，保留已验证的两个存储域、备份清单及其 `.d` 目录副本。
2. 一并重新构建当前 Host、Client 和生成的 Remote 定义，打开“设置 → 主动消息”，启用开关并保存所需周期和限制；投递需要空闲角色会话及已配置模型。
3. 重启后核对策略仍然保留，已发送消息带有真实助手回执；进一步操作前，在原会话检查待发送或不确定记录，入队本身不代表成功。
4. 回滚前停止新版进程，完整恢复已验证的升级前主存储与备份，不要剥离字段或重写不可变 Session 历史。详细计时与恢复行为见[主动消息](../../../genesis/social.zh.md)。
