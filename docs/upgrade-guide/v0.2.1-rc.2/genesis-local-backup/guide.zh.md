# Genesis 本地备份与记忆记录

[English](guide.md) | 中文

## 变更

Genesis 每次提交主状态后会写入本地备份，默认路径为 `${leasePath}.backup.json`。主状态缺失但备份存在时，启动会失败，而不是创建另一个生命。备份失败可能发生在主写入成功之后，并会停止依赖状态的操作。

可选语义记忆流水线增加可选的记忆分类、归属和向量字段。旧记录无需转换即可读取，但旧版严格实现会拒绝含有这些字段的记录。

## 迁移

1. 确认 Genesis 进程可写入备份目录，或在插件配置中设置与 `leasePath` 不同的绝对 `backupPath`。保留同一主存储和写入锁。
2. 重启并验证备份与主存储 `states/life` 包含相同身份。提交或备份失败时停止并检查两份数据，不要为了创建新生命而删除备份。
3. 启用可选 `memory` 块前，保留经验证的升级前存储副本以便降级。嵌入和模型设置，以及将独立备份恢复为 Storage Domain 记录的方法，见[记忆配置与恢复](../../../genesis/memory.zh.md)。
