# Genesis 记忆身份、日期与个人文件

[English](guide.md) | 中文

## 变更

整理选中记忆会原子替换并删除所选旧条目，不再保留重复记录。模型使用简短来源编号，生命事件 ID 不能指代选中记忆。新生成正文在内部使用准确日历标记，角色回忆时保留重要准确日期，普通经历相对显示。手动编辑、分类转换和删除直接更新当前状态，不新增修改事件或历史版本；既有会话日志和原有历史保留。

可选的操作者资料和当前习惯证据排除集合扩展生命持久化数据，旧版严格读取器会拒绝包含这些字段的快照。自定义 Genesis 组合现在必须提供 `sandboxPolicy`。生命覆盖配置启用持久个人目录，学会读写后会在所有对话模式告知路径，明确授权仍受文件策略限制。

## 迁移

1. 升级前备份现有生命域、备份文件、凭据库与模型／嵌入设置。保留原 `DSH_HOME`、存储和租约，不要通过重建身份处理读取错误。降级应恢复完整升级前备份，不要删除未知字段。
2. 重建受影响的主机和浏览器包，并通过支持的 `dsh` 配置重启。自定义 Genesis 组合须提供 `sandboxPolicy`，基于 base 的配置已有该服务。不设置 `personalDirectory` 即可关闭目录功能，或使用生命覆盖配置的 `$DSH_HOME/personal`，文件须另行备份。已记录目录必须私有、归当前身份所有且保持同一规范位置；目录缺失须恢复。
3. 在设置 → 记忆 → 你的身份填写姓名和身份。配置独立写入模型与嵌入后保存，以安全替换现有泛指角色称呼。所有批次一起提交；完整旧记忆集合超限时可提高 `memory.identityRewriteLimit`。失败会保留原身份和记忆。
4. 整理前检查选择，成功后新结果替换旧条目，生命事件证据仍保留。核对新条数，失败可使用保留的选择重试；并发编辑须刷新。
5. 主机时区不适合时，将 Genesis `timeZone` 设置为所需 IANA 时区。重要准确日期使用 `{{date:...}}`（每年生日可用 `--MM-DD` 省略年份），普通 `{{time:...}}` 标记相对显示。整理增加一次基于原始证据、写入日志的模型语义检查。程序只渲染明确标记，普通词语、年龄、版本号和未标记的人工正文保持原样。语义检查失败会保留选择。详见[记忆](../../../genesis/memory.zh.md)与[个人目录](../../../genesis/awakening.zh.md#personal-directory)。
