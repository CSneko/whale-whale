# Genesis data model

[English](data-model.md) | 中文

## 概要

持久记录由所属[校验定义](../../packages/experimental/genesis/src/model.ts)规定。域版本 1 保留对经校验旧快照的读取，新写入使用 `genesis-split-v1` 清单，并重建 `schemaVersion: 1` 的生命数据。身份与历史不绑定模型名称、会话 ID、用户 ID 或提示词。

## 记录

| 记录 | 含义 |
|---|---|
| 身份 | 稳定的品牌化生命 ID、可空名称、固定诞生时间、更新时间、核心版本与初始框架及版本。 |
| 生命事件 | 品牌化事件 ID、生命 ID、类型、时间、来源、JSON 数据、稳定去重键与可选会话及事件引用。 |
| 记忆 | 品牌化记忆 ID、类别、内容、创建和更新时间、重要性、置信度、必须存在的来源事件 ID，以及可选的陈述性或非陈述性分类、归属和嵌入空间及向量缓存。 |
| 兴趣 | 品牌化兴趣 ID、自由主题、当前推断阶段、原因，以及带来源事件 ID 的独立完成交流。 |
| 能力 | 以工具名为品牌化能力 ID，保存声明摘要、首次观察和变化时间、作用域可用性、执行时权限检查与最近使用结果。 |
| 成长 | 品牌化成长 ID、系统类别、时间、标题、描述与关联生命事件 ID。 |

记忆的可选 `experience`、`experienceIds`、`history` 和 `habit` 字段保留事件情境、派生关联、带来源的以往认识与条件习惯。生命的可选 `consolidation` 游标保存待处理修订、来源 Session、操作者偏好、重试次数与最近的安全结果，行为与预算由[记忆参考](memory.zh.md)定义。可选的版本 3 `emotion` 保存九项即时情绪、二维心境、独立心理需求、恢复参数、修订、单操作者关系及可选操作者 `controls`，并与带来源的变化事件原子提交；评估与恢复见[情绪](emotion.zh.md)。缺少可选字段的记录仍可读取；情感版本 1 和 2 须离线手动转换后才能加载。转换或降级前须保留可信的升级前备份。

可选 `interests` 启用时从空清单开始。每次接受的阶段变化及其引用来源与追加式生命事件一起提交；无变化评估也记录重放标记。此字段保存在 `projections` 组件中，跨 Session 恢复。[兴趣](interest.zh.md)说明阶段与限制。缺少 `interests` 的旧状态仍可读取；旧版严格读取器会拒绝新写入的字段。

可选版本 1 `agency` 投影保存品牌化动机、生命目标、决策、目标变化历史及实际执行结果引用，并要求对应初始化事件与有效来源。变化与生命事件原子提交，复用既有容量、独立备份和恢复机制；缺少此字段的旧状态可读取，旧版严格读取器会拒绝新字段。数据结构和状态规则见[动机与审议](motivation.zh.md)。

## 一致性与恢复

`genesis` 域保留一条原子提交的 `states/life` 清单。不可变组件位于 `genesis_records` 域，使用现有 JSON 后端的逐记录布局或 SQLite 记录。JSON 目录分别为 `identity`、`events`、`memories_episodic`、`memories_semantic`、`memories_self`、`memories_procedural`、`embeddings`、`memory_history`、`growth`、`capabilities` 和 `projections`，文件名为内容的 SHA-256 摘要。清单保留记录顺序，并在所有引用组件持久化后才发布。域校验检查记录归属、唯一 ID 和去重键、唯一且匹配的诞生事实，以及记忆和成长来源是否存在。仅基础模式的初始记忆与诞生事实不会分开提交；新建的唤醒模式生命没有个人记忆。命名、首次会话和已学工具记录为幂等生命事件，学习不代表可用或已获授权。

两个域使用配置的 Storage Domain 路由；备份时需包含两者，选择专用后端时也需配置两个域的路由。无需更改 SQL 表结构。启动在开放生命数据前验证组件摘要和跨记录约束。引用的记录缺失、格式损坏或版本不兼容时拒绝启动；中断写入留下的未引用记录不参与恢复，并在成功提交后清理。I/O 失败可能导致持久结果未知，因此持久化失败后核心停止服务直到重新加载。输入或容量拒绝不修改已提交数据。

保留历史受可配置记录数及序列化字符上限约束。容量耗尽时拒绝新写入，不丢弃历史。提交复用未变化的组件，替换清单，并在独立备份成功后移除已被替代的记录。启动和校验仍加载完整的有界生命数据；清单大小随记录数增长。

记忆扩展字段在读取时可省略：旧记录保留身份和来源，缺少分类时将过程类记忆视为非陈述性，其余视为陈述性。旧版严格读取器会拒绝包含扩展字段的记录，因此降级前应保留经验证的升级前副本。本地备份和审核语义由[记忆参考](memory.zh.md)定义。

旧版完整快照在下一次成功启动时转换，生命 ID、诞生时间、事件顺序和来源关系保持不变。旧版严格读取器拒绝新清单。升级前请完整备份两个域及独立备份；绝不把不兼容数据当作空生命。
