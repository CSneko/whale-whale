# Genesis data model

[English](data-model.md) | 中文

## 概要

持久记录由所属[校验定义](../../packages/experimental/genesis/src/model.ts)规定。域版本 1 与记录中的 `schemaVersion: 1` 拒绝不兼容读取。身份与历史不绑定模型名称、会话 ID、用户 ID 或提示词。

## 记录

| 记录 | 含义 |
|---|---|
| 身份 | 稳定的品牌化生命 ID、可空名称、固定诞生时间、更新时间、核心版本与初始框架及版本。 |
| 生命事件 | 品牌化事件 ID、生命 ID、类型、时间、来源、JSON 数据、稳定去重键与可选会话及事件引用。 |
| 记忆 | 品牌化记忆 ID、类别、内容、创建和更新时间、重要性、置信度与必须存在的来源事件 ID。 |
| 能力 | 以工具名为品牌化能力 ID，保存声明摘要、首次观察和变化时间、作用域可用性、执行时权限检查与最近使用结果。 |
| 成长 | 品牌化成长 ID、系统类别、时间、标题、描述与关联生命事件 ID。 |

## 一致性与恢复

一条 `states/life` 记录同时提交身份、事件、记忆、会话观察与成长。域校验检查记录归属、唯一 ID 和去重键、唯一且匹配的诞生事实，以及记忆和成长来源是否存在。初始记忆与诞生事实不会分开提交。

现有 JSON 与 SQLite Storage Domain 后端均支持该表示，不新增 SQL 表结构或迁移框架。I/O 失败可能导致持久结果未知，因此持久化失败后核心停止服务直到重新加载。输入或容量拒绝不修改已提交数据。

保留历史受可配置记录数及序列化字符上限约束。容量耗尽时拒绝新写入，不丢弃历史。当前每次写入替换完整快照，更大规模历史需要显式迁移与增量存储设计。

未来迁移必须保留生命 ID、诞生时间与来源关系。转换前备份完整存储单元，绝不把不兼容数据当作空生命。
