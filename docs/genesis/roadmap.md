# Genesis next steps

English | [中文](roadmap.zh.md)

## Summary

The next development steps build on actual life facts and sourced candidate memories. They are proposals, not available capabilities.

## Priorities

1. Add reviewed memory promotion, correction and deletion flows in Web settings, with visible source evidence and distinct user assertions versus confirmed observations.
2. Add incremental durable event storage and a versioned migration/export path before raising history capacity for long-running use. Retain immutable life identity throughout migration.
3. Extend runtime observation with installed/enabled plugin metadata and actual provider versions, without conflating those states with Session authorization or successful use.

## Later phases

Optional [emotion appraisal](emotion.md) and [experience-derived interests](interest.md) connect to [motivation and deliberation](motivation.md), with persistent goals, independent choices and a trusted event entry. Later work can use the existing scheduler for controlled awakening, followed by reflection, skill development and reviewed self-improvement.

Computer operation, video creation and external-site interaction require separate capabilities and explicit authorization. Nothing in Phase 1 installs them or grants publishing permission.
