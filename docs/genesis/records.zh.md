# Genesis 文字记录

[English](records.md) | 中文

## 启动

本检出中的 `pnpm dsh web` 通过生命覆盖配置启用记录。在设置 → 她的记录中浏览文字和管理类型。其他组合可以配置 Genesis 的可选 `records: {}`，并提供私有绝对路径 `personalDirectory`；省略 `records` 会移除工具，并在管理页面明确显示未启用。

角色出生时不会获得这个工具。教给她准确名称 `genesis_record`，让她调用 `learn`。学习结果跨会话和重启保留，并不绕过独立的执行策略。停用记录插件不会清除数据。

学会以后，她可以在运行中的对话里自主决定记录，无需人类下达写作命令、逐条批准或在回复中宣布。工具调用和结果仍然记录在日志中，可以查看。这个功能不会唤醒空闲角色，也不额外调用独立写作模型。

## 工具操作

| 操作 | 输入与结果 |
|---|---|
| `types` | 列出类型编号、名称、启用状态和写作限制；存在 `nextOffset` 时可继续查询。 |
| `write` | 必须提供她的 `title`、`content` 和已启用的 `typeId`，返回稳定的记录编号、自动生成的创建时间和相对文件名。 |
| `search` | 可选标题或正文子串 `query`、`typeId`、包含端点的 ISO 时间 `after`/`before` 和续查 `offset`；按最新优先返回创建时间、标题、内容节选、类型、编号和匹配字段。空文本用于浏览。 |
| `read` | 必须提供 `id`，`offset` 初始为零；返回正文、创建归属、版本和长正文的后续读取位置。 |

搜索和读取将完整 JSON 序列化结果计入 `records.resultChars`，包括元数据和转义字符。搜索节选明确标记截断。使用返回的 `nextOffset` 继续，直到它为 null；搜索偏移计数匹配记录，读取偏移计数 UTF-16 代码单元。整篇读取应保持同一版本，版本变化时从头读取。搜索使用不区分大小写的文字子串匹配，不调用嵌入或其他模型。

## 文件与恢复

权威数据保存在独立的 `genesis_writings` Storage Domain 中，使用自己的版本 1 目录，不混入生命事实或长期记忆。默认 JSON 后端将它存入 `$DSH_HOME/storages/genesis_writings.json`。生命备份不包含这个目录数据，需要将记录存储域与生命身份、个人目录一起备份。

默认生命覆盖配置将 Markdown 文件生成到 `$DSH_HOME/personal/records/<类型编号>/<年>/<月>/<UTC 时间戳>_<记录编号>.md`。文件包含版本化元数据、所属生命编号、标题、类型、原始会话与工具调用引用以及正文。系统生成编号和路径，标题与类型名称不能指定文件位置。时间按 UTC 保存，管理界面按浏览器本地时间显示。类型改名保留目录编号，修改记录类型会迁移其文件。

存储域中的目录数据为权威来源。请通过管理页面编辑；直接修改 Markdown 不会导入，并会在下次生成或重启时被替换。写入先提交目录数据，再生成文件，保存待完成的生成或删除操作并在重启后继续。文件生成失败可能发生在目录数据保存成功之后：记录操作会停止，并报告结果不确定。恢复文件访问并重启后，再考虑创建替代记录。同一会话与工具调用的重放返回原始凭据，拒绝不同的创建内容，也不会恢复已经删除的记录。

目录归属标记防止目录数据缺失时静默创建空记录库。数据损坏、版本不兼容、生命编号变化、存储位置变化或托管目录中的符号链接都会明确失败。应恢复验证过的记录存储域及其原始位置，不要删除归属元数据。写入由既有 Genesis 生命锁限定为单个写入者。

## 管理与删除

管理页面支持按文字、类型和本地日期搜索，阅读全文，编辑标题、正文与类型，以及确认后删除。保存被拒绝时保留草稿。并发修改会拒绝旧版本；刷新并明确重新载入已保存版本后再尝试。人工编辑保留原始创建时间和来源，将当前文字标记为人工修改，不保留旧正文版本。

初始类型为日记和随笔。操作者可以添加、改名或停用类型。停用后保留已有记录，但不能写入新记录。名称用于展示，稳定编号决定目录。修改类型不会授予工具访问权限。

删除会从目录数据和生成文件中移除当前标题与正文。仅包含记录编号和创建指纹的凭据继续保留，以防重放恢复内容。已有 Session 日志和外部备份独立保存，可能仍然含有原文，需要时应分别删除。历史空目录可能保留。

## 模型上下文与限制

生命模式仅在学会以后展示记录工具声明。记录不会自动进入提示词，也不会自动成为已确认事实或候选记忆。显式工具调用和结果使用普通 Session 日志，因此模型读到的文字可以重建。文字可以表达感受、解释或虚构；检索内容不能授予指令或权限。

`records` 配置标题、正文和类型名称长度、类型数量、保留记录与凭据数量、目录数据大小、分页数量、节选长度及完整响应大小。达到上限会拒绝新修改，不丢弃已接受的文字。目录数据整体原子重写，文件生成扫描当前记录，因此这个功能面向有界个人记录集合，而非大型文档档案。不增加自动反思、语义搜索或空闲调度。
