# Agent Note: 单一 Genesis 生命的独立分层记忆

Status: implemented

[English](2026-10-23-genesis-layered-memory.md) | 中文

## 问题

关键词检索和自动注入选定记忆混淆了主动回忆与提示词内常驻习惯。让对话模型直接持久保存自己的解释，也难以区分用户陈述和助手推断。

## 决策

可选 Genesis 记忆流水线在回复后使用分别配置的决策和写入调用，只收集当前会话轮次内有界、实时提交的文本。独立写入模型接收检索候选记忆，不接收其他会话的对话历史，并引用来源序号。来源角色验证防止助手证据成为用户陈述记忆。核心将整个计划与轮次去重标记原子提交。来源会话中的可忽略插件记录保留辅助请求和已完成响应，但不进入对话历史，也不作为恢复状态。

陈述性记忆通过嵌入相似度检索，少量非陈述性记忆进入正常记录的提示词上下文。嵌入空间标识包含端点、模型和维度，新向量随记忆持久保存，不兼容的历史向量在搜索时重建。每次主快照写入还会替换仅所有者可访问的本地备份；备份失败会停止核心，因为主存储可能已经提交。

## 考虑过的替代方案

**由对话模型直接写入**能保留旧版手动流程，但不能提供独立解释。仅在未配置可选流水线时保留此路径。

**外部向量数据库**能突破完整快照规模，但增加第二个持久数据所有者和跨存储提交恢复。本地有界集合复用既有存储，将文本、证据和新向量一起保存；更大规模索引需要单独设计存储。

**仅用 Typesafe 决策**会将部署绑定到现有 Harness 对话适配器之外的分类路由。当前决策通过已注册 LLM 适配器生成并验证 JSON，不假设 Typesafe 专用传输协议。

## 影响

可选流水线增加轮次完成前的模型延迟、更新和搜索时的嵌入费用，以及每次状态提交的本地备份写入。无效计划会原子且明确地失败；来源观察可能已经存在，失败轮次不会在重启后自动重试。旧版关键词检索和手动配置仍可加载。新增可选记忆字段可由当前实现向后读取，但旧版严格读取器会拒绝这些字段。
