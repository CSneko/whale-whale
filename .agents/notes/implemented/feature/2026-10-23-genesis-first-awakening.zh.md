# Agent Note：单一 Genesis 角色与显式工具学习

Status: implemented

[English](2026-10-23-genesis-first-awakening.md) | 中文

## 问题

仅共享生命 ID 不能提供首次交流体验，也无法区分已学工具和运行时注册表。只过滤声明仍允许伪造执行调用，而默认编程提示词与能力清单会在学习前泄露工具。

## 决策

可选唤醒路由要求独立记忆流水线。现有生命记录在设置前预留身份；认证命名操作准备对话及辅助模型路由，并探测嵌入服务，然后一次性提交名字。既有 API 配置和账号登录继续管理凭据。首次接受的交流记录为一条生命事实，不把消息存入全局状态。

角色使用完整提示词和有界生命上下文，替换默认编程助手指导和可选上下文。最初只展示 `learn`。学习成功须检查调用者实际作用域中的注册表，提交一条幂等生命/成长事件，并在后续请求及其他会话中开放该工具。工具上的单调拒绝检查独立阻止未学工具执行，包括直接调用。其他授权策略仍有最终决定权。工具移除后保留学习记录，但记录不能让缺失或受作用域限制的工具变得可调用。

## 考虑过的替代方案

**会话内学习**在用户新建对话时丢失连续性。已学工具属于生命，可用性和对话上下文属于各自会话。

**仅隐藏声明而不检查执行器**允许模型编造工具调用。单调拒绝检查不能被允许执行的瀑布监听器覆盖。

**在提示词中自动发现工具**违背所需的学习体验。底层注册表仍供可信主机代码使用，但清单和编程指导不进入角色的初始请求。原生展示方式避免 PTC SDK 清单泄露。

## 后果

可选生命覆盖配置与浏览器配套插件提供先配置凭据再命名的流程，基础配置仍可加载。尚未学习回忆工具时，独立记忆评审也能保存自我介绍。共享生命持久保存名字、人设记忆和学习记录，无关会话不接收旧对话。免密 Loader 集成验证命名失败、伪造执行、记忆连续性和重启；录制的无界面会话固定初始学习声明及角色提示词。真实服务认证与回复质量需要配置服务后验证。
