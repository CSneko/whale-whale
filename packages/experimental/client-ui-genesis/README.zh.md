# @deepseek-ai/dsh-experimental-client-ui-genesis

[English](README.md) | 中文

## 概述

通过独立“生命信息”、“知识库”、“记忆”和“情绪”页面查看身份与成长，配置 Jev 决策、独立写入模型和嵌入服务，并浏览带来源记忆。密钥使用既有凭据库，五个预设共享生命与记忆。“初始化生命”由用户在新对话界面或设置页主动点击，命名后进入首次生命对话，成功完成后按钮消失。“不再出现”会持久关闭自动配置提醒，不新增网络监听端口。

## 使用

将本包 `cordis.patch.yml` 与 [Genesis 核心覆盖配置](../genesis/README.zh.md) 一同应用于具有预设注册表的 Web 或桌面配置，启动前重新构建浏览器包。[首次唤醒教程](../../../docs/genesis/awakening.zh.md)启用命名与首次问候。“生命信息”负责命名、身份和成长，“知识库”负责决策/写入/嵌入配置。“记忆”负责有界搜索、新增、编辑、删除和分类转换，展示经历时间、关联经历 ID 与可展开的以往认识，说明记忆如何形成和变化。可选生命预设成为部署默认值，已有用户默认选择优先。

启用[兴趣](../../../docs/genesis/interest.zh.md)后，“生命信息”还展示当前推断阶段、来源 ID 和有界变化历史。此页面不编辑兴趣。

“记忆”还提供持久化的自动巩固开关、立即执行、最近具体错误，以及习惯情境、响应和证据。预算与取消规则见[空闲巩固](../../../docs/genesis/memory.zh.md#automatic-habits-and-idle-consolidation)。

“设置 → 情绪”展示九项即时反应、二维心境和独立心理需求、事件解释及有归属的有界历史。“设置 → 关系”管理五项单操作者估计，分别标明证据置信度或明确人工设置，支持带原因的修订检查编辑。编辑器支持填写原因后手动调整、暂停自动评估，以及配置情绪、自然恢复及关系变化共用的敏感度。编辑检查修订并跨重启保存；写入失败保留草稿，成功关闭弹窗后仍有独立提示。参见[情绪管理](../../../docs/genesis/emotion.zh.md#operator-management)。 情绪设置编辑器还可保存停机计时策略和即时情绪、心境的两个耦合增益，并提供本地化行为说明。

“设置 → 主动消息”通过所属已认证 Remote 保存启停、目标会话、定时和投递限制，展示采样时的渠道可用性、最近确认的助手消息及有界触发、决策、回执历史。保存失败保留草稿，待发送和不确定结果均明确标注，详见[主动消息](../../../docs/genesis/social.zh.md)。

“记忆”提供多选与手动整理，可归纳为一条或多条认识，成功后原子替换原始记录，失败时保留选择。生命预设包含内置[时间感知](../../context/time-context/README.zh.md)，提供已记录的时间读数与浏览器时区提示，见[整理选中记忆](../../../docs/genesis/memory.zh.md#selected-memory-organization)。

记忆页面提供可展开的操作者身份表单。保存时会安全替换现有记忆中的旧角色称呼，冲突会保留草稿。直接编辑和转换不新增历史。编辑器保留稳定日期标记，角色回忆时保留重要准确日期，普通经历相对显示，详见[身份与记忆时间](../../../docs/genesis/memory.zh.md)。

<a id="implementation"></a>
## 实现

插件挂载所属包生成的 Remote，注册 `genesis` 资源提供方并贡献本地化设置页面和每条已完成回复的手动记忆入口。端点编辑通过带版本检查的生命配置存储保存，密钥使用既有凭据库，不进入配置或记忆。设置失败时显示受影响的操作和具体原因，包括 HTTP 状态码、校验字段或连接错误码，不显示密码原文或服务端响应正文。记忆和情绪设置显示最近已评估轮次及完成时间，包括无需变化的结果；Jev 决策还显示更新概率与本次阈值。聊天和知识库中的记忆失败显示失败阶段和安全诊断，重试错误保留自身原因，新失败轮次会重置重试提示。保存失败时保留草稿；刷新后点击“重新载入配置”可载入最新已接受的值。共享资源模型负责已读取数据，并在失败后保留旧值。凭据/设置/服务变化、对话运行状态变化、用户刷新与重连会请求新样本，插件不运行轮询定时器；资源中止会取消 RPC 并释放刷新监听器。

设置 → 性格与说话风格分组展示长期自我倾向及过程类的说话、行为习惯。专用有界读取先筛选这些条目，不受无关记忆预览挤占。添加、编辑、转换和删除复用现有带版本检查的记忆操作与编辑器，写入被拒绝后保留草稿。此页面不调用模型，也不提供特质分数控件。

角色和记忆指令由主机生命插件负责。本配套插件通过既有 Session API 创建首次会话，请求主机加入已记录的内置唤醒。提供方检查会准备已配置路由，端点检查通过模型列表验证认证，嵌入测试执行一次请求。记忆文本搜索和直接增删改不执行推理。每条回复的手动生成使用原始对话证据和独立写入模型，跳过决策模型并强制所选分类，同时保留自动评估。版本检查、来源与重试行为见[记忆管理](../../../docs/genesis/memory.zh.md)。

设置 → 她的记录通过已认证的记录 Remote 浏览、搜索、读取、编辑和删除角色文字，并管理类型。共享按需资源在失败后保留数据，捕获的草稿与版本检查保护编辑；删除、归属与恢复见[文字记录](../../../docs/genesis/records.zh.md)。

<a id="model-experience"></a>
## 模型体验

无，本页面仅通过有界 Host 操作管理 Genesis 状态，不会将设置或记忆预览发送给聊天模型。

#### KV 缓存影响

刷新仅读取主机状态，不追加对话事件或调用推理模型。接受的情绪调整与恢复设置影响后续已记录的生命上下文，暂停情绪评估会停止其辅助调用；相关模型影响由[情绪](../../../docs/genesis/emotion.zh.md)定义。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 此视图按需采样，仅在唤醒模式提供一次性命名，不替换身份、不确认记忆、不编辑权限，也不持续轮询。
- 返回预算可能省略预览，数量与省略提示会明确区分；历史非活动会话的工具不会作为实时能力展示。
